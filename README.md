# 你画我猜

纯AI代码。小程序啊网页版啊找了好几个用起来都不太舒服，总有设置不太满意，所以让Claude搓了一个。网络安全性估计是一坨，但我不在意(。)

和朋友一起玩的网页版你画我猜。在群里发一个链接，大家用手机浏览器点开就能玩，不用装 App，用电脑浏览器也行。服务器跑在你自己手里，规则和词库都可以自己改。

*A self-hosted, phone-first Pictionary (你画我猜) for a group of friends. Chinese UI; Python backend, vanilla JS frontend. Developer and AI-agent docs: [AGENTS.md](AGENTS.md).*

## 有什么不一样

- **猜对了只显示星号**：别人看到的是「小王：\*\*\*」，星号的个数就是答案的字数；猜错的话，原文照常显示。
- **提示可以调**：字数提示可以开或关。画手还能主动揭开某个字，比如 `_ 颈 _`，代价是之后的得分会打折。
- **时间可以调**：作画时长可以设，第一个人猜对后要不要缩短倒计时也可以设；画手可以点「+10 秒」给自己加时。
- **词库自己定**：往 `words/` 文件夹里放 txt 文件，一行一个词。
- **画画工具不多不少**：画笔和橡皮（都能调粗细）、一键清空、7 种颜色。
- **为手机设计**：竖屏布局，画画时页面不会跟着滚动；掉线后会自动重连，分数和进度都还在。
- **国内也能打开**：页面不加载任何外部字体或 CDN，不会因为某个资源被墙而打不开。
- **能改的都在配置文件里**：人数、时长、计分、颜色等都在 `config.toml` 里改，不用碰代码。

## 怎么玩

1. 一个人开服务器（见下面的「安装」和「开服务器」），打开网页，点「创建房间」。
2. 把房间链接发到群里，大家点开、起个昵称就能进来。创建房间的人是房主。
3. 房主在等待界面选词库、圈数、时长等，人齐了就点「开始游戏」。
4. 大家轮流当画手：画手从几个候选词里选一个画出来，其他人在聊天框里猜。猜得越快，得分越高；每有一个人猜对，画手也得分。
5. 打满设定的圈数后显示排名，然后回到等待界面，可以直接再开一局。

房主还可以踢人，也可以跳过当前这一轮。

## 安装

需要 Python 3.12 或更新的版本（3.12 和 3.13 都测过），以及 fastapi 和 uvicorn 两个库。推荐用 conda 单独建一个环境，这样不会影响电脑上别的 Python。

1. **下载代码**：在 GitHub 页面点 **Code → Download ZIP** 然后解压，或者用 `git clone`。
2. **装 conda**：推荐 [Miniforge](https://github.com/conda-forge/miniforge)，用 Miniconda 或 Anaconda 也行。已经装过的话跳过这一步。
3. **建环境**：打开 **Miniforge Prompt**（如果装的是 Anaconda/Miniconda，就打开 Anaconda Prompt；macOS 和 Linux 打开终端），进入项目文件夹，运行：
   ```
   conda env create -f environment.yml
   ```
   这会建出一个叫 `nhwc` 的环境。以后更新了代码、依赖有变化时，运行 `conda env update -f environment.yml --prune`。

不想用 conda 的话，也可以用 Python 3.12 以上的版本自己建一个虚拟环境，然后运行 `pip install -r requirements.txt`。

## 开服务器

**Windows**：双击 **`start-server.bat`**。它会自动找到 `nhwc` 环境里的 Python。

> 如果提示找不到 Python：在项目文件夹里新建一个 `python-path.txt`，只写一行，内容是 python.exe 的完整路径。
> - 查这个路径的方法：在 Prompt 里先运行 `conda activate nhwc`，再运行 `where python`，第一行就是。
> - 这个文件只留在你的电脑上，不会被 git 提交。

**macOS、Linux，或者用命令行**：

```
conda activate nhwc
python main.py
```

启动后，窗口里会显示两个地址：

```
本机打开:      http://localhost:8000
同一 Wi-Fi 下: http://192.168.1.5:8000
```

### 一、在家里玩（同一个 Wi-Fi）

连着同一个 Wi-Fi 的手机打开第二个地址，点「创建房间」，再把房间链接发给其他人。

**手机打不开？**
- **Windows**：第一次启动时，防火墙可能会弹窗询问，选「允许 Python 访问专用网络」。如果当时点了拒绝，到「Windows 安全中心 → 防火墙 → 允许应用通过防火墙」里把 Python 勾上。
- **macOS**：系统询问是否允许 Python 接受传入连接时，选「允许」。

### 二、让外地的朋友也能进来

一共三种办法，从上往下越来越稳定，但也越来越麻烦。

#### 方案 A：临时公网地址（最快，几分钟就能搞定）

Windows 双击 **`start-online.bat`**；macOS 和 Linux 运行 `python main.py --online`。它会在**同一个窗口**里做两件事：

1. 启动游戏服务器。这时服务器**只接受公网地址转来的连接**，同一个网络（比如校园网）里的其他人不能直接连到你的 IP。
2. 用系统自带的 `ssh` 连到免费服务 [localhost.run](https://localhost.run)，拿到一个形如 `https://xxxx.lhr.life` 的网址。

把这个网址发给朋友就行。
- **关掉这个窗口，服务器和公网地址会一起关闭**；公网连接自己断了的话，服务器也会跟着停。
- 端口用的是 `config.toml` 里的 `port`。

- **优点**：不用注册，不用装软件，也不用碰路由器。
- **缺点**：
  - 网址每次都不一样，关掉窗口就失效；
  - 免费服务的速度和稳定性没有保证，国内能不能顺畅打开也不一定；
  - **拿到网址的任何人都能进来**，别把网址发到公开的地方；
  - 所有流量都会经过 localhost.run 这个第三方服务。
- 第一次运行时，ssh 可能会问 `Are you sure you want to continue connecting`，输入 `yes` 再回车。

> 作者 2026 年 10 月实测过：用手机流量能打开，也能正常玩。在国内打开顺不顺畅还没测过。如果打不开，或者游戏里一直显示「正在重新连接」，就换方案 B 或 C。

#### 方案 B：路由器端口转发（家里的电脑当服务器）

1. 登录路由器管理页面（一般是 `192.168.1.1` 或 `192.168.0.1`），找到「端口转发」或「虚拟服务器」，把**外部端口 8000** 转发到**这台电脑的 IP（就是上面「同一 Wi-Fi 下」那个地址）的 8000 端口**。
2. 在系统防火墙里放行 8000 端口（TCP，入站）。
3. 用 [ip.sb](https://ip.sb) 之类的网站查到你的公网 IP，朋友打开 `http://公网IP:8000` 就行。

**注意：**
- 很多宽带没有真正的公网 IP（运营商级 NAT）。如果路由器上显示的 WAN 地址和 ip.sb 查到的不一样，这个方案就用不了。
- 家里的公网 IP 可能会变，可以配合 DDNS 使用。
- 电脑要一直开着。

#### 方案 C：租一台 VPS（长期玩最推荐）

一台每月几美元的 Linux 小服务器就够用。如果朋友分布在美国和国内，选机房时可以考虑：

- **美国洛杉矶**：要选带国内优化线路的，比如标着 CN2 GIA 的。
- **日本东京**：离国内近，离美国也不算远。

这两个地方到美国东部、中部和国内的延迟都比较平均。服务器在境外，不需要备案。

在 Ubuntu 上部署：

```bash
# 1. 装 Python，把项目放到 /opt/nhwc（git clone 或者 scp 上传都行）
sudo apt update && sudo apt install -y python3 python3-venv
sudo useradd --system --home /opt/nhwc nhwc
sudo mkdir -p /opt/nhwc && sudo chown nhwc /opt/nhwc
# ……把项目文件放进 /opt/nhwc ……

# 2. 建虚拟环境，装依赖（VPS 上用 venv 就够了，不需要 conda）
cd /opt/nhwc
sudo -u nhwc python3 -m venv .venv
sudo -u nhwc .venv/bin/pip install -r requirements.txt

# 3. 设成开机自启、崩了自动重启
sudo cp deploy/nhwc.service /etc/systemd/system/
sudo systemctl enable --now nhwc
sudo systemctl status nhwc        # 看到 active (running) 就好了

# 4. 在 VPS 的防火墙或安全组里放行 8000 端口
```

Ubuntu 24.04 及以上自带的 python3 就是 3.12，可以直接用。更老的系统要先装一个 3.12 以上的 Python，再用它来建 `.venv`。

部署好以后，朋友打开 `http://VPS的IP:8000` 就行。

想要正式的域名和 https（在微信里更不容易被拦截）：
1. 买个域名，指向 VPS。
2. 装 [Caddy](https://caddyserver.com)，在它的配置里写 `你的域名 { reverse_proxy 127.0.0.1:8000 }`。它会自动申请证书。
3. 页面会自动改用 `wss://` 连接，不用改代码。

## 改配置

所有可调的东西都在 **`config.toml`** 里，每一项都有注释。改完后要**重启服务器**才会生效。常用的几项：

| 想改什么 | 配置项 |
|---|---|
| 一个房间最多几个人 | `[room] max_players` |
| 至少几个人才能开始 | `[room] min_players` |
| 画画的颜色、粗细档位 | `[drawing] colors / brush_sizes / eraser_sizes` |
| 每局的默认设置：圈数、作画时长、缩短倒计时、加时等 | `[modes.classic]` |
| 计分 | `[modes.classic.scoring]` |
| 端口 | `[server] port` |

每局的设置（词库、圈数、时长、要不要提示字数等），房主也可以在等待界面里直接改，只对这个房间生效。

配置写错的话，服务器启动时会直接报错，并告诉你是哪一项错了。

## 加词库

- 在 `words/` 文件夹里新建一个 `.txt`，文件名就是词库名，比如 `动物.txt`。
- 一行一个词。空行会被忽略，`#` 开头的行是注释，重复的词会自动去掉。
- 编码用 UTF-8 或 GBK 都行，用 Windows 记事本直接保存的文件也能读。
- **不用重启**：回到等待界面，就能在设置里勾选新词库。
- 自带的是 `默认.txt`，大约 300 个常见、好画的词。
- 你自己加的词库**默认不会被 git 提交**，因为里面可能有朋友之间的梗。想公开某个词库，就运行 `git add -f words/词库名.txt`。

## 常见问题

- **在微信里打开很卡、老断线？** 点右上角「···」，选「在浏览器打开」。页面上方也会出现这个提示。
- **切到别的 App 再回来？** 会自动重连，分数和进度都还在。
- **画手掉线了？** 等 15 秒，这一轮会自动跳过。
- **房主掉线了？** 60 秒后，房主身份会自动交给下一个人。
- **一个人在两个页面同时打开？** 后打开的那个生效，前一个页面会提示「已在其他页面打开」。
- **服务器重启后？** 所有房间都会消失，需要重新创建，因为数据只存在内存里。
- **conda 或 pip 下载很慢？** 在国内可以把 conda 和 pip 换成清华或中科大的镜像源。

## 已知问题

- iPhone Safari（特别是弹出键盘时）和微信内置浏览器，还没在真机上完整测过。遇到问题欢迎提 issue。
- 一幅画的笔画太多（超过 10 万个点）之后，画手还能继续画，但别人看不到新画的部分。正常玩基本碰不到。

## 安全和隐私

- **没有账号和密码**：拿到房间链接的人都能进来。别把链接或公网地址发到公开的地方。
- **什么都不保存**：房间、聊天、画都只在服务器内存里，关掉服务器就没了。也不收集任何统计信息。
- **没有防刷**：没有限制发消息和建房间的频率。适合朋友之间玩，不适合长期对所有人开放。
